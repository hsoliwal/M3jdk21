# M3JDK21

**M3JDK21** is the Java 21 product/runtime target for M3 work by Hitesh Soliwal,
Contributors, and Synexia. M3 focuses on reducing redundant CPU work and retained
memory through M3Index/precomputation, mechanical transformation, reusable
recipes, and verification while preserving required JDK behavior and contracts.
