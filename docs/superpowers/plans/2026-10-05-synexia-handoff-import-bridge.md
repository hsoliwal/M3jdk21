# Synexia Handoff Import Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Make a source-generated Synexia handoff tree mechanically importable and verifiable in M3jdk21, then prove one real capability reaches the existing typed receiver without manual product-source copying.

**Architecture:** Reuse the existing `SYNEXIA_M3_HANDOFF_V1` exporter and destination hash-pinned snapshot recipes. Add path-backed packet verification and a guarded resource importer that copies only migration-recipe resources after complete preflight; product source still changes only through the existing OpenRewrite receiver recipe. Complete the existing `synexia-mindex-joined-streams-v1` packet with its exact Java payload/manifest and verify fixed-point reception against the already-equal target owner.

**Tech Stack:** Java 21, Maven, JUnit 5, OpenRewrite 8.17.1, SHA-256, GitHub source-pinned resources.

**Spec:** `m3/docs/synexia-source-bridge.md`

## Global Constraints

- No runtime dependency from `java.base` or HotSpot to Synexia.
- No public JDK/JNI ABI change.
- Importer may write only under `m3/tooling/migration-recipes/src/main/resources`.
- Complete preflight precedes every write; destination drift and symlinks fail closed.
- JAVA payloads remain typed Java receiver inputs; TEXT/NATIVE remain exact UTF-8 snapshots.
- Product source mutation remains owned by the existing hash-pinned OpenRewrite recipes.
- `m3/docs/name-mapping.json` remains canonical mapping authority.
- No merge, rebase, force-push, or installed-JDK replacement.

## Review Focus

- Extra/unexpected files in an exported handoff must be rejected rather than silently ignored.
- A destination resource that differs by one byte must block the whole import before any write.
- Symlinked export or destination paths must be rejected.
- Re-importing identical resources must be a zero-change fixed point.
- Real `MIndexJoinedStreams` source bytes must remain identical across source packet, receiver payload, and destination owner.
