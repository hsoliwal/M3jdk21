## Mechanical behavior and complexity
- Replace `Object[] operations` copied in full by every append with immutable `Object[][]` pages of up to 64 operations, keeping primitive `size` and a `long[] filterMask` (one word per page).
- On append, copy only the partial page and page-directory/mask arrays; share completed pages without mutation. Parent and forked plans remain independent. Per-stage callback objects are those the application already created; no entry nodes are added.
- Sequential evaluation iterates page and lane offsets; short-circuit, exception object identity, source liveness, null inputs/results, stable sortedToList and encounter-ordered distinctToList are retained.
- Construction for k appends: prior full-array copying O(k²); paged O(64k+k²/64). Each terminal remains O(rows × k) for callbacks, O(1) interpreter stack. No JNI signature or native library is touched by this leaf.
