# Reuse and attribution

This packet reuses the existing M3JDK21 collections owner, native implementation, test main and hosted build owner without modifying or copying their implementation. Source identities are in SOURCE_PINS.json. The module LICENSE and SPDX declarations identify Apache-2.0; existing copyright and notices remain in their source files.

JDK, GCC/MinGW-w64 and Python are execution tools. Their binaries, libraries and sources are not redistributed by this evidence packet. TOOL_PINS.json records the static candidate files used for reproducibility; it does not claim an exhaustive operating-system dependency closure.
