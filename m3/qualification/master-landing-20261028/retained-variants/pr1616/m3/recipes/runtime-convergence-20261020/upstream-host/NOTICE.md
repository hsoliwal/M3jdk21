# Source rights and reuse

The reusable recipe owners are unchanged Synexia Apache-2.0 sources at commit `11c94feb18155a53cc213708c353791132edc4a7`. New task recipe tests, receiving adapters, catalogues and documentation are Apache-2.0 with the stated Synexia project copyright.

All resource preimages and postimages retain the notices of their receiving source files. A template or recipe does not relicense its generated code. OpenJDK-derived Java/C files and associated copied proofs retain GPLv2 plus the Classpath exception where their headers specify it. The external collection wrappers and their first-party donor atom retain Apache-2.0. Exact historical copies remain historical copies.

The catalogue's external GitHub implementations were inspected for compatibility and license obligations; no external implementation was copied into these payloads. Challenge and tutorial sites supply taxonomy only. The catalogue records selected first-party commits, paths and blobs, and identifies source-only candidates separately from executed proofs.

Full Apache-2.0 text is retained in `licenses/Apache-2.0.txt`. The String crate additionally retains the receiving OpenJDK license text in `licenses/OpenJDK-GPL-Classpath.txt`. Original per-file notices remain authoritative.
