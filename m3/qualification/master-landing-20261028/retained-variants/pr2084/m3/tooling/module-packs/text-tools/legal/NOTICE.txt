Unix4j wc semantics (jdk.m3.text.Wc, native/m3textio.c)
The wc line/word/char counting and output layout port the observable semantics of
Unix4j (https://github.com/tools4j/unix4j, commit
0a127602907978efbff7ea297bd553274ba70a8e: org.unix4j.unix.wc.CounterType,
org.unix4j.unix.wc.Counters, org.unix4j.util.StringUtil). No Unix4j source file is
included; the Unix4j 0.6 jars are used only as a test oracle. Unix4j notice:
