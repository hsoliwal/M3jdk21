No production Java/JNI implementation, profile validator, language tokenizer or runtime Lucene dependency is introduced.

Tests distinguish source identities sharing a record ID, exact literal offsets, original UTF-16 projection, supported-empty vs unsupported results, cold/warm typed payloads, independent returned arrays and closed-catalog behavior. Pattern/engine/language/minima/normalization context is retained. The generic runtime stores those fields but does not enforce a new linguistic semantic profile.
