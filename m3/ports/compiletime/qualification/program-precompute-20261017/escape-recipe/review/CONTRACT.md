# Prepared escape contract and proof obligations

## Frozen semantic owner

For a fixed method instruction list, its existing ASM `SourceInterpreter`
frames and the scanner's exact callee classification table, let `p -> q`
mean that the retained forward classifier admits a source dependency from
producer `p` to copy instruction `q`. Let `U(p)` be the bitwise union of
the retained direct-consumer masks seeded at producer `p`.

The forward query at a site `s` returns the union of `U(p)` over all producers
reachable from `s` by those dependency edges. The prepared equation is
`M(p) = U(p) | OR(M(q) for p -> q)`. A monotone worklist initialized with
the direct-use seeds computes its least fixed point, so `M(s)` is the same
union. The finite eleven-bit lattice makes cycles terminate. This proof
preserves the owner's deliberately conservative DUP and array-provenance
behavior; it does not substitute an unrelated ownership definition.

The only correction to the frozen forward implementation is its omitted
`SWAP` copy. ASM records `SWAP` as the source of both exchanged category-one
values. The original owner did not extend taint through that instruction.
The permanent witness obtains a handle, exchanges it with another stack
value, and writes it to a static field. The original classifier returns zero
instead of `FIELD`; corrected forward and prepared paths return `FIELD`.
The regression additionally loads and executes valid generated bytecode on
the VM, checks both operand positions and alias chains, and retains a
separate invalid category-two `SWAP` analysis-failure case.

## Byte-for-byte obligations

The gate compares the original `escape` method and all following source
with the candidate after removing exactly one added `SWAP` case line.
The original callee classifier is therefore retained, including exact
`requireNonNull` descriptors and overloaded annotations. It compares the
harvester candidate with its preimage after exactly three local identifier
substitutions. Both constraints fail closed on any additional change.

The public scanner's `javap -public` output must be identical. Tests preserve
site order, bytecode offsets and FNV site identity, complete mask unions,
null/dead frames and the existing frame-analysis failure contract. All
instructions in the fixed corpus are compared with the corrected forward
oracle, not merely the final obtaining-site rows.

## Resource and lifetime obligations

The caller skips zero-site methods through its existing guard, uses the
corrected forward query for exactly one obtaining site, and prepares the
shared graph for repeated sites. This admission choice follows the retained
one-site CPU/allocation comparison; it does not change any returned mask.
The same four executable one-site SWAP fixtures now exercise the caller's
forward choice while their direct all-instruction checks still exercise
the prepared solution. The existing multi-site scanner fixtures and
differential graph corpus remain unchanged.

The optional graph is local to a method invocation. The scan never caches
it globally. The returned `int[]` contains only mask values and retains no
instruction, frame, descriptor, callee table or spelling objects. Callers
must hold the method, source frames and policy fixed during preparation.
Independent concurrent calls return separate arrays; later policy changes
require a fresh call and cannot change earlier answers.

CSR offsets and source IDs are primitive arrays. Duplicate dependencies are
allowed and charged. Bounds cover dependency entries, charged source visits
and declared primitive payload; VM headers, ASM frames and temporary
descriptor/key objects are explicitly outside that payload count. Every
budget refusal falls back to the corrected forward path. Tests cover exact
limits, one-below refusal, negative budget validation, null/empty frames,
loops, joins, all legal DUP/SWAP categories and complete accumulated masks.

CPU and allocation measurements distinguish the existing per-site forward
queries, cold preparation plus all site lookups, and prepared-array reuse.
They use fixed already-computed ASM frames. Actual retained-array bytes
come from `Instrumentation.getObjectSize`; the separate `4*N` payload
column is arithmetic, not a whole-process memory measurement. Neither
finite parity nor a measured synthetic shape establishes a universal
performance or general escape-analysis claim.

## Additive failure history and scope

The initial whole-port compile failure is preserved as the exact duplicate
`destination` diagnostic. The requested input binding is renamed locally,
and both original harvester tests remain untouched. The historical source
custody checker is separately reproduced as stale and is not resealed.

This task masters the existing Maven/OpenRewrite snapshot owners and emits
five exact target files. It qualifies full compile-time-port Java source
and JUnit behavior with its source dependencies. It does not qualify the
whole product Maven reactor, a rebuilt JDK image, native/JNI execution,
dynamic reference counts, GC/lifetime permission, or phase advancement
beyond `PROVING_GROUND_CANDIDATE`.
