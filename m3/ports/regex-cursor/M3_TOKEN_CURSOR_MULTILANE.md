### Null diagnostic identity

On the Java 21 runtime used for qualification, the original `Arrays.stream(null)` emits an enhanced NullPointerException message from its argument dereference. To avoid changing this incidental observable diagnostic for invalid callers, the candidate preserves the original `Arrays.stream` call **only** on the null-outer-array refusal branch; normal valid multi-lane execution uses no stream and allocates no stream pipeline. Inner nulls keep the original `Objects.requireNonNull(inner)` exception site. The Java version-dependent diagnostic is verified against the original source rather than frozen to a hardcoded text string.
