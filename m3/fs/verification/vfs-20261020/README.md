# Completed qualification and remaining gates

The seven-test canonical SDK suite passed for the final shared-default and
capture extension. The exact emitted sources were admitted before runtime
compilation. `RESULTS.json` records the actual source count and generated-only
JUnit counts. Production overlays were not used. The independent named consumer
ran on the fresh image built by the existing shared JMOD packer.

`MFileContent` progress, shadow and capture defaults share one stream state.
Completion publication requires actual input EOF and successful primary close.
The capture includes sampled metadata, separate capture time, complete observed
SHA-256/count and an existing raw manifest. Word-ID and AST references remain
optional, generation/derivation-qualified outputs from their existing owners.
Known sampled size conflicts refuse capture; no source-stability assertion is
inferred from matching timestamps or sizes.

Original Apache and dependency legal bytes are retained and verified through the
JAR, six vendored JMODs and linked image. Read `qualification.json`, its source
lock and dependency inputs, and the consumer log for the actual bounded image
run. The supplied toolchain is identified in the command and acquisition receipts.

The existing native owner was built with strict GCC flags and unchanged C sources.
All twelve C suites and 45 generated JNI declaration/export checks passed. The
native Java test receipt records the separately executed required-native tests.
The existing runtime packager then produced an image whose mandatory JNI probe
loaded both M3FS and SQLite from that image. The independent named VFS/capture
consumer passed on the same image, with 132 legal-entry comparisons. Native input
and image hashes are distinct because jlink may strip debug data.

This native lane directly executes the existing CMake owner's source/flag/test
closure; it does not claim CMake/CTest execution. The full Maven lifecycle attempt
remains blocked by the unavailable offline exec plugin. Optional FUSE is disabled
and sanitizers were not rerun in this lane. The supplied-JDK image does not
establish a complete source-built M3JDK21. Upstream tests, optional transports,
Git/LFS hydration and broader future acceptance rows remain unqualified.
