It implements the public API contract of org.apache.commons.collections4.map.PassiveExpiringMap from
Apache Commons Collections 4.5.0 (Copyright 2001-2025 The Apache Software Foundation, Apache License,
Version 2.0) and links the Commons Get, IterableGet, IterableMap, Put, MapIterator and ResettableIterator
interfaces and the PassiveExpiringMap.ExpirationPolicy type. No Commons implementation code is included.
The module tests also load the unmodified commons-collections4-4.5.0.jar classes as a differential test
oracle, with one constant-pool class name redirected to a test clock.
