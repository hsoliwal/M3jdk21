Spring Framework core 6.2.0 (Copyright 2002-2024 the original author or authors, Apache License,

The module includes Apache License 2.0 source originating from Spring Framework
v6.2.0 by the original Spring authors (Copyright 2002-2024): the public
org.springframework.util.MultiValueMap, package-private MultiToSingleValueMapAdapter
and SingleToMultiValueMapAdapter, and org.springframework.lang.Nullable.
Modified 2026 by Hitesh Soliwal and contributors: Spring Assert and
CollectionUtils helpers replaced with JDK checks; the fromMultiValue factory
uses the first-party M3MultiValueMapAdapter; the runtime Nullable marker
omits JSR-305 qualifier alias meta-annotations. Each file retains its original
upstream copyright/license block and carries the modification notice.
The Spring Core and JSR-305 JARs are test-only donor verification inputs,
not production/runtime dependencies. Whole Spring Core source is not included.
