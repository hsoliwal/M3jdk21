# M3JDK21 primitive array/offset/bitmap rank bulk receiving slice

M3JDK21 is one integrated Java/HotSpot/JNI SDK product. The four Java products in SOURCE_MANIFEST.tsv were generated by the canonical Synexia Maven/OpenRewrite source template `m3-indexpath-bulk-20261021`, then received directly in their existing `m3/collections` owner/module. Synexia does not become a runtime dependency.

The new `M3IndexPathRank.Window.copySelectedRowIds(selectedFrom,output,outputOffset,count)` is an additive caller-owned bulk primitive output method. It reuses the existing owner's immutable `int[]` row payload, logical selection bitmap `long[]`, `int[]` prefix counts and zero-copy source window. It neither creates per-row Entry objects nor stores another list/tree. The existing `toArray()` delegates to the same bounded bit-word walker for identical selected order.

Existing comparator/predicate callbacks are not moved or elided. The method does not call callbacks or new JNI symbols. The existing native-required mask selector remains untouched; the original native parity contract was extended to compare its output with the new bulk path while retaining `-Xcheck:jni` enforcement.

Selection uses bit masks and signed physical/index offsets; duplicate row IDs, negative strides, nested windows, all/mixed/empty selections and full signed-bit31 masks are covered by the generated JUnit and standalone oracle.

**Review / acceptance:** Original public JDK collection interfaces, callbacks, C ABI, installed Java runtime and original return types are unchanged. This is a new internal M3 collection capability, not complete migration of five provider collection families. Original source/target SHA256, OpenRewrite recipe, exact Java copies, donor category decisions and lossless second application are in canonical Synexia crate. Full source-built JDK/JTreg/JCK, provider ABI, Windows/macOS native, GC/CDS, retained heap/native allocations, and performance gates remain NOT_RUN until executed. String→arrays→collections receiving order remains locked.
