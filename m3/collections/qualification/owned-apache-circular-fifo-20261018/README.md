M3CircularFifoQueue is a complete owned array-ring implementation of the Apache CircularFifoQueue public Queue/BoundedCollection operation surface. It owns one element array, start/end offsets and private bit-state flags; it stores no entry nodes and uses no provider implementation superclass, delegate, factory or helper. The inherited JDK AbstractCollection contracts operate through its owned iterator.

The implementation preserves default capacity32, positive arbitrary capacities, collection-copy constructors, oldest-element eviction, null rejection before eviction, FIFO/get order, wrapped iterator removal, and original nonfailfast iterator policy. isFull() remainsfalse because another insertion is always accepted; isAtFullCapacity() reports size==capacity. The donor's nonfinal class and constructor subclass dispatch are preserved. A narrowly scoped this-escape annotation retains that pre-existing behavior under strict Java21 lint; the identical original donor/prototype compiler refusal remains recorded.

The same prewritten fixture passes 1,033,638 checks and 95,060 protocol operations for Apache 4.5.0 and the owned class, against independent collection and cursor references. Public constructor/method signatures match after the declared class/package relocation. That narrow observation supports the absence of per-insertion nodes; it is not a throughput result or a guarantee for all workloads. The donor's O(1) basic FIFO and O(n) interior-removal complexity is unchanged.
