# Source attribution

The text snapshot engine is imported verbatim from first-party Apache-2.0 source at Synexia commit bc1634ab0387288e677afd563a01782b90aae618, Git blob 9d0788d3717e017d58345c5c3e62022c2915a3c8. Its SPDX and copyright headers remain intact.

All six catalogue templates preserve the exact frozen first-party TSV/Markdown data and their donor revision, rights and proof-boundary statements. No donor implementation is copied by this receiving recipe. The original catalogue reuse decisions remain in ../FOSS_REUSE_DECISION.tsv, and the local source receipt remains ../catalogue-data-receipt.json.

OpenRewrite and JUnit are Maven dependencies. The test-only reader uses JDK string/collection APIs for the sealed tab-separated records.
