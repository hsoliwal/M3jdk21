## Reproduction

Run the canonical crate with a Java 21 `JAVA_HOME` through the existing Maven control plane:

```sh
mvn -B -ntp -Pcontract -Dm3.contract.target=/absolute/path/to/M3jdk21 verify
python3 receive.py --target /absolute/path/to/M3jdk21 --check
python3 receive.py --target /absolute/path/to/M3jdk21
```

The public proof mirror includes the four unchanged SDK owner sources under `sdk-owner/src/main/java`. In that mirror pass `-Drecipe.owner.root="$PWD/sdk-owner"` to Maven. The receiver selects that local owner directory automatically. Retain a fresh actual SDK report and input binding before receiving; historical receipt text cannot substitute for a current run.
