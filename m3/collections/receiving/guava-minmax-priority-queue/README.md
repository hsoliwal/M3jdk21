# Receive the exact owned MinMax source

The canonical engine is unchanged. The single target transitions from ABSENT to the exact38983-byte source, or accepts that exact postimage. PlainText mode establishes source custody; strict Java21, unchangedV5 behavior and actual snapshot JNI qualification supply separate proof.

Original two-test pattern: eight absent/present/order/unrelated input states with fresh fixedpoints, and four drift/duplicate refusals before additions/edits. It preserves existing source identity, IDs, markers, bytes and paths. No consumer type/interface is rewritten.

The installed module requires external com.m3:m3-collections:0.1.0-SNAPSHOT and Guava33.4.8-jre Ordering API. The recipe never installs a provider backing implementation.
