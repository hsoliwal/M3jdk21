# Disclosure scope for the bounded five-provider extension

This task composes source already public in hsoliwal/M3jdk21 at
4e29dc9d4141261e8763fbe9ffd6a20e017b1aff with the pinned, publicly distributed
Guava, Apache, Eclipse and Spring contracts inventoried in donor-intake.json.
The target already publishes M3LinkedHashMap key-only stable slots, M3SlotArrays,
M3IndexPathMasks Java/C17, primitive count/state owners and the previous optional
interop factories. The extension adds ordinary array-column count bookkeeping,
provider adaptation and contract tests over those existing owners. It does not
introduce or reproduce unpublished invention-specific algorithms, a patent claim,
or a change to existing license grants. It is classified as public maintenance
and attributed interoperability adaptation for this exact source packet.

The canonical reusable recipe remains in the private Synexia repository. Its
Apache-2.0 snapshot engines may be mirrored for offline authoring/proof under the
existing source-reuse policy; engine hashes and the canonical commit are retained.
The classification is a custody decision for these files, not a patentability,
inventorship or legal-priority conclusion. Any later addition of unpublished
invention-specific material needs its own review under the repository policy.
