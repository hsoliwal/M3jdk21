## Reviewable bounded Java addition
The additive com.m3.file.M3FileDelta keeps immutable, sorted String[] paths, role byte[], long[] lengths and packed 32-byte SHA-256 lanes for source, class, build-input, resource and dependency observations. Optional class ABI digests are explicitly supplied compiler evidence, never inferred from SHA-256 or filenames. M3FileDeltaCli accepts two typed manifest TSVs and two explicit build-context hashes; it emits a read-only deterministic change receipt usable by Maven, Gradle or other build hosts. The fixture M3FileDeltaSelfTest tests actual unchanged M3File, actual javac-generated .class deltas, detached record projections, symlink/bounds refusal, counterexamples, insertion/order stability, ABI-attestation uncertainty, deletion and class/source roles. No retained Entry/Node wrapper per observation.

No full-tree implicit discovery, cache replacement, file mutation, inferred source-to-class mapping, annotation-processor lifecycle skipping, or task execution occurs. The build host must include environment/compiler flags, build scripts/plugins, JDK/toolchain versions, processors, declared and undeclared observed inputs, classpath and outputs in its own opaque build-context digest, and prove its own completeness. ABI facts must be compiled/attributed in M3AST or a trusted tool; matching externally supplied facts alone do not certify safe reuse. Missing or volatile context and processor effects must fail closed. SHA and SimHash do not prove semantic equivalence. A snapshot is not transactional against simultaneous source changes.

## Build-system integration boundary
Maven Compiler Plugin 3.13.0 default incremental detection may rebuild all sources in a module when a dependency/source changes; disabling it blindly may miss downstream references. The official Maven Build Cache extension hashes module input/output state. Gradle already has incremental Java compilation, compile avoidance, build cache and configuration cache. Use their declared lifecycle/input contracts; M3FileDelta can provide additional exact source/class evidence, **never a competing SKIP/UP-TO-DATE decision**. The m3-mvn/m3-gradle tool-pack launchers continue invoking original distributions and are unchanged.
