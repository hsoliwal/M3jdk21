## HumbleUI Skija 0.143.18 and HumbleUI Types 0.2.0

### Origin

The Java and native binding sources of the module `jdk.m3.graphics` are derived from:

- HumbleUI Skija 0.143.18 (https://github.com/HumbleUI/Skija), `shared/java`: 217 types. Three of them,
  `impl.Cleanable`, `impl.ReferenceUtil` and `impl.ResourceFinder`, come from `shared/java9`: they are the
  `META-INF/versions/9` classes of the Multi-Release `skija-shared` jar, the ones a Java 9 or later runtime loads.
- HumbleUI Types 0.2.0 (https://github.com/HumbleUI/Types), sources of `io.github.humbleui:types:0.2.0`: 7 types.

The native bindings come from `platform/cc` in HumbleUI Skija commit
`44c99d7a92fe68a29b3233f8ca55b0d29d8f6f68`, the same 0.143.18 revision as the Java sources.
They are compiled into this module's `m3graphics` native library. The module does not require a Skija JVM library.

Both are licensed under the Apache License, Version 2.0.

### Changes made by Synexia (2026-10-31)

The Java sources were transformed as follows:

- Lombok annotations were expanded with `lombok.jar delombok` 1.18.48, then the generated markers were removed. One helper
  class was added, `jdk.m3.graphics.impl.M3SneakyThrow`.
- The JetBrains documentation annotations were removed: `@ApiStatus`, `@NotNull`, `@Nullable` and `@Contract`.
- Packages were renamed: `io.github.humbleui.skija[.x]` and `io.github.humbleui.types` became `jdk.m3.graphics[.x]`, and
  `io.github.humbleui.skija.impl` became `jdk.m3.graphics.impl`.
- Every type `T` was renamed `M3T`. The one string literal that names a class file, `"Library.class"` in
  `M3Library`, became `"M3Library.class"`. The references of the Javadoc tags (`{@link}`, `{@linkplain}`,
  `{@value}`, `@see`, `@throws`) follow the same rename (2026-11-01); their labels and the prose are the donor's.
- Line ends became LF, and trailing blanks were removed.

The public API is otherwise the donor's, member for member: the javap surface is equal after the rename.

### Native integration changes (2026-11-15)

- JNI exports and native class and method descriptors use the existing `jdk.m3.graphics` names.
- Native declarations follow the unchanged Java signatures emitted by `javac -h`.
- The retained typeface factories use the platform font manager. The retained bitmap volatility hint is
  maintained as per-bitmap advisory state, including copy, subset, swap, reset and destruction behavior.
- The legacy four default typefaces retain their identities and normal-width selection. Paragraph line
  limits retain the full Java `long` result and the unlimited sentinel instead of an intermediate `int` cast.
- Unsupported platform backends report `UnsupportedOperationException`; their supported-platform
  implementations retain the original Skia guards.
- Native loading uses the module's installed library, retains the legacy loader properties and explicit
  legacy filename support, and resets loader state if initialization fails.
- The two-argument text-blob intercept method delegates to the paint-optional overload.
