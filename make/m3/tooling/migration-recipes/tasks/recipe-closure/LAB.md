The primary recipe owners remain M3AtomizePureIntReturnRecipe, M3PatternizePureIntAtomRecipe, M3DocumentPureIntAtomRecipe and their existing composite. This task adds test infrastructure, not a production transformation engine. Use stock JavaCompiler with in-memory source and bytecode file objects, isolated class loaders, fixed seeds, explicit budgets and the actual OpenRewrite recipes. Disable annotation processing during generated compilation; never relax OpenRewrite type checks.

The immutable original multi-file project is compiled independently. Every intermediate candidate is compiled and executed against the same corpus, not merely compared with its predecessor. Enumerate binary arithmetic/shift/bit operators crossed with nested unary/parenthesis variants, plus comments, literals, null/exception/effect controls, shadowing and member-surface checks. Both supported atomizer/patternizer orderings must converge in a bounded number of sweeps; test that a one-sweep budget fails when a replay witness has not occurred. A refusal/no-op on every positive input is a failing test. Inject a wrong value and invalid source to prove the verifier detects wrong candidates. Fresh complete replay must produce no changes. Captured source/recipe hashes and counts are reports, not universal semantic-equivalence proof.
