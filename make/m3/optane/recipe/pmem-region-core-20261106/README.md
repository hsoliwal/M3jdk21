# recipe pmem-region-core-20261106: the PMem region core relocated into jdk.m3.optane

Leaf `pmem-region-core` (plan `C:/m3-superset/conv/plans/fs-pmem.tsv` rank 2, the foundation of ranks 3-5) of the
M3JDK convergence programme: the persistent-memory region family of `hsoliwal/com.synexia` `m3-pmem-sdk` becomes part
of `m3/optane` (Maven `com.m3:m3-optane`, module `org.m3jdk.optane`, package `jdk.m3.optane`) by recipe, never by hand.

## Recipe

`python -I make/m3/optane/recipe/pmem-region-core-20261106/relocate.py --donor-git <clone> --donor-rev 36827ee8a798 [--check]`
(`RELOCATE_PMEM_REGION_CORE` v2, derived from `m3/native/recipe/scoped-leases-20261106/relocate.py` v1). It rewrites only
the license header (in the file's comment style: `//`, `/* */`, `#`, `<!-- -->`), the `package` line, mapped `import`
lines, the declared type names (`Pmem* -> M3Pmem*`, `NativePmem -> M3NativePmem`, also inside the message
`"foreign PmemRegion owner"` and the Javadoc links), the dotted donor package inside literals and prose, the JNI symbol
and header prefixes, and the declared TEXT rows; it inserts one `FLLDCIM: RELOCATE` anchor naming the donor blob URL at
the donor commit. Every other byte is kept (22 of 22 files `body_match_renamed=TRUE`; `body_match=TRUE` only for the C
oracle, which has no name to rename). A BLOB row pins one file to another blob at a commit that holds it (refused
otherwise). Idempotent: `--check` reports `changed=0 provenance=UNCHANGED`, also after `jdk_naming.py apply`.

## Licence boundary

All relocated code is Apache-2.0 (same copyright holder as the donor). `libpmem2` (PMDK, BSD-3-Clause) is an optional
compile-time dependency of `m3pmemsdk.c` only: the CMake option `M3_OPTANE_PMDK` is OFF by default, the gates built
without it, and no PMDK source or binary is in the tree or shipped (`legal/NOTICE`). With the option OFF,
`M3PmemBackend.PMDK` fails closed with `UnsupportedOperationException` and `AUTO` is POSIX.
