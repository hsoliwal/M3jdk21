Naming collisions with existing String members: split(String) is regex, so commons split(str, separatorChars) becomes tokenize(String). concat(Object...) would be ambiguous next to concat(String) with null arguments, so it is named concatAll. Kotlin slice(indices) clashes with JS slice(begin,end), so it becomes sliceIndices. lodash words() clashes with UAX#29 words(), so it becomes wordsByPattern. The new codePointCount() is an overload of the existing codePointCount(int,int). indent(String,Predicate) overloads indent(int). strip/stripStart/stripEnd(IntPredicate) overload the String-set forms. isBlank(IntPredicate) overloads isBlank(). lines() already returns a Stream, so the List/keep-ends variants need distinct names (splitLines, lines(String,boolean), linesLf, linesUnicode). commons substringAfter returns '' when the delimiter is missing, but Kotlin returns the original string; choose one convention before landing.
