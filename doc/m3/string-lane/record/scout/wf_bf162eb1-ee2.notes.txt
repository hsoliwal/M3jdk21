FACTS THAT DECIDE EXACTNESS
- Class bits are set only on ASCII units (M3StringFacts.java 344-379). (regexAllClasses & X) != 0 on a non-empty String proves every unit is ASCII and in X. A clear all-bit proves "not all" only when facts.ascii. The empty String has every all-bit set (scan starts from REGEX_CLASSES): guard length > 0.
- REGEX_SPACE is space plus U+0009..U+000D. Character.isWhitespace is also true for U+001C..U+001F and for non-ASCII separators. The SPACE mask therefore answers whitespace questions only in the "true" direction, even for ASCII text. The exact whitespace measures are stripStart / stripEnd.
- Character.isDigit / isLetter / isLetterOrDigit / isLowerCase / isUpperCase restricted to ASCII equal DIGIT / ALPHA / ALNUM / LOWER / UPPER (from the Character definitions; not executed here).
- bitSignal64 folds A-Z onto a-z (M3StringFacts.java 605-610): unit presence is ASCII-case-blind and is a rejection gate only.
- asciiLowerHash folds only A-Z on every unit: an exact rejection for Guava Ascii.equalsIgnoreCase on any text, but for String.equalsIgnoreCase only when both sides are ascii (already coded so, String.java 2491-2495).
- charAt on a tuple descends the DAG per unit (M3StringTuple.java 35-39). CodeUnitCursor (M3String.java 862-915) reads by scalar run.
- M3String.asciiCase (M3String.java 1728-1751) has no caller in the java.lang files read.
- String.isBlank / strip / trim on an M3-backed String call facts(), which prepares everything (candidate SU-1).
